## 매번 같은 시간을 빼고 있다면

여러 모임에 참여하다 보면 "월, 수 저녁엔 항상 수업", "주말 오전엔 늘 약속"처럼 **매번 똑같이 빠지는 시간**을 이벤트마다 다시 표시하게 됩니다. **내 스케줄**은 이렇게 반복되는 일정을 미리 한 번만 등록해 두는 기능이에요. 등록해 두면 이벤트에 참여할 때 가능한 시간이 자동으로 채워져, 매번 처음부터 시간표를 칠하지 않아도 됩니다.

내 스케줄은 두 가지로 이루어집니다. 매일 자는 시간 범위인 **수면 시간**, 그리고 요일별로 늘 바쁜 시간대를 표시하는 **주간 고정 스케줄**입니다. 이 둘을 등록해 두면 "내가 비어 있는 시간"이 정해집니다.

![마이페이지의 내 스케줄 화면 — 수면 시간과 요일별 고정 일정이 한눈에 보임](/images/guide/recurring-schedule/overview-ko.png '내 스케줄 화면')

> 주의: 내 스케줄은 **로그인한 사용자만** 사용할 수 있습니다. 등록한 스케줄은 계정에 저장되므로 게스트로 참여할 때는 적용되지 않아요. 자주 모임을 잡는다면 로그인해 두는 것을 권장합니다.

## 수정 화면 열기

마이페이지에서 **내 스케줄**로 들어간 뒤 **수정**을 누르면 편집 화면이 열립니다. 여기서 수면 시간과 주간 고정 스케줄을 차례로 설정합니다.

![내 스케줄 수정 화면 — 수면 시간과 주간 스케줄 보드가 차례로 보임](/images/guide/recurring-schedule/edit-ko.png '내 스케줄 수정 화면')

## 수면 시간 설정하기

먼저 매일 자는 시간을 정합니다. **시작 시간**과 **종료 시간**을 각각 드롭다운에서 고르면 됩니다. 예를 들어 23:00 ~ 07:00으로 두면 그 시간대는 어떤 이벤트에서도 가능한 시간에서 자동으로 빠집니다. 시작과 종료를 같은 시간으로 두면 수면 시간 없음으로 처리됩니다.

![수면 시간을 시작, 종료 드롭다운으로 설정하는 모습](/images/guide/recurring-schedule/sleep-ko.png#lg '수면 시간 설정')

## 주간 고정 스케줄 표시하기

아래 보드는 가로로 시간대, 세로로 **요일**(월~일)이 놓인 격자입니다. 매주 늘 바쁜 시간대의 칸을 눌러 표시하세요. 수업, 근무, 정기 모임처럼 매주 반복되는 일정을 칠해 두면 됩니다. 잘못 누른 칸은 다시 눌러 해제할 수 있어요.

![요일별 보드에서 고정으로 바쁜 시간대를 칠해 표시한 모습](/images/guide/recurring-schedule/weekly-ko.png '주간 고정 스케줄 보드')

## 저장하기

설정을 마쳤다면 상단의 **저장**을 눌러 마무리합니다. 저장한 내 스케줄은 계정에 보관되어, 이후 어떤 이벤트에 참여하든 자동으로 반영됩니다. 일정이 바뀌면 언제든 이 화면으로 돌아와 수정할 수 있어요.

## 다음 단계

요일별 일정을 일일이 칠하기 번거로운 대학생이라면, 다음 편에서 **에브리타임 시간표**를 그대로 가져오는 방법을 확인해 보세요. 바로 이벤트에서 어떻게 쓰이는지 궁금하다면 마지막 편으로 건너뛰어도 좋습니다.
